Section 1: Olivine (Correct)

1) Copy the content of ol_01032017_oxide.txt and ol_01032017_ratios.txt into a single file.
2) Rearrange columns if needed (Ex. Comment column to the beginning and then SiO2)
3) Check at the standards (SC-Olivine in Comment column) and plot them in a scatterplotThen check each element standards and visually select the erroneous outliers.
4) Calculate average and stdev also now can copy the ground truth standards (which are in Standards.xlsx but a couple values can be found in ol_01032017_std-cnd.txt with virtually the same values but with higher precision) and finally calculate the correction factor CF = mean/ground truth). Here is when we can visually inspect the data, drop outliers if they are biasing the mean or if the data seems right, calculate the correction factor that will be used to correct all values later by dividing it to all the values (notice that all these steps are supposed to be visual, so no fancy alhgorithms are needed; or can be used but definitely don't have to be reported). At this point it would be good to have a .xlsx file of the standards and all the values if possible.
5) After calculating all the corrections factors flag the ones that are above or below 5% (might be faulty measurements, need to be reported)
6) Notice that after correcting the values the accuracy becomes 1 because we shifted the mean to match the ground truth, one way around might be (optional step) to take for example 2 standards per batch and calculate the mean with that value, then use the combination of the missing standards to calculate a second new mean that will be sligthly different from the corrected data and we can get an accuracy estimate.
7) Optional as well, we can use the Fo+M and Fa+M measurements to recalibrate our FeO or MgO measurements if they are faulty or with too low precision, in that case we can recalibrate using the atomic weights (maybe worth to report as well).
8) Now we can calculate the (relative) precision and accuracy with the new corrected values, here the preferred standard deviation for the caluclations is 2 sigma.
9) Next we can now create a clean copy of the corrected values and discard the standards, it is also worth to flag any sample that has less than 98% or more than 102% total, if it is more we have a problem and should be reported, if it is less it may be admisible because we might have lost volatiles in the sample. Also this is the time to flag any anomalous measurement that might be erroneous and can be skipped for the figures (it will depend on the variability of the data, the values flagged must be obviously erroneous) (it needs to be reported in the data quality section though)(notice that an explanation is not necesary, since we don't know the conditions and is not part of the exercise)(it might also be helpful to report the detection limit to explain why some relative precisions are large for some elements).
10) Done all values corrected and ready for plots.
